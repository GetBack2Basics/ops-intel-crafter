GeoLibre Open GIS Project Spec

What is the GeoLibre Project Spec?
The operational-intelligence-crafter.geolibre.json file contains the declarative spatial definition of this emergency operations model, including hazard zones, critical infrastructure, population matrices, and direct GCS lakehouse GeoParquet connections.
Desktop GIS Integration (GeoLibre, QGIS, ArcGIS Pro):
1
Download Project Spec: Save the JSON file below to open in your desktop GIS.
2
Open with GeoLibre: Launch the desktop application or open GeoLibre WebGIS and drag & drop the project file.
3
Direct GCS Lakehouse Streaming: DuckDB & QGIS query GeoParquet directly from gs://operational-intelligence-crafter-lake/ without copying massive files locally.
